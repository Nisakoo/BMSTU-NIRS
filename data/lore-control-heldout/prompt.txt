ЗАДАЧА

1) Сгруппируй все 54 названия в 18 троек по общей теме и составь по одному
   вопросу на тройку. Каждый id должен войти ровно в одну тройку.
   - Вопрос пиши как живой пользователь, который ищет эти эпизоды: 8–20 слов,
     естественный русский язык, без канцелярита.
   - Используй обычные тематические слова, но не перечисляй в вопросе ответы.
   - Не выдумывай фактов, которых нет в названии (числа, имена, события).

2) Придумай 5 вопросов-ловушек: ответа на которые в этих эпизодах заведомо
   нет (точные числа, марки, пароли, даты, личные данные).

3) Для каждого обычного вопроса укажи:
   - relevant_documents: три id из его тройки;
   - reference_answer: 1–2 предложения общего вида, что показывают эпизоды;
   - required_facts: 2–3 коротких слова в начальной форме (например: дружба,
     подарок, победа).
   Для ловушки: reference_answer строго «В документах нет этой информации.»

ФОРМАТ ОТВЕТА — только YAML, без пояснений:

questions:
- id: q1
  text: <вопрос>
  kind: normal
  relevant_documents:
  - <id>
  - <id>
  - <id>
  reference_answer: <ответ>
  required_facts:
  - <слово>
- id: t1
  text: <вопрос-ловушка>
  kind: trap
  reference_answer: В документах нет этой информации.

ПРОВЕРЬ ПЕРЕД ОТВЕТОМ
- ровно 18 normal и 5 trap;
- у normal ровно 3 relevant_documents и 2–3 required_facts;
- у trap нет relevant_documents и required_facts;
- каждый из 54 id использован ровно один раз;
- id вопросов: строчные латинские буквы, цифры, «_».
