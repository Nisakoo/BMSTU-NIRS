# Docker

Этот каталог предназначен для контейнерного запуска серверной части проекта.

Здесь должны находиться:

- `compose.yaml` — backend с агентом и инфраструктурные зависимости RAG;
- Dockerfile серверных компонентов;
- `.env.example` — документированный шаблон переменных окружения;
- вспомогательные скрипты и конфигурация контейнеров.

Frontend в Compose не входит и запускается отдельно.

RAG является инструментом агента внутри backend. При необходимости его база данных или векторное хранилище могут запускаться отдельным инфраструктурным контейнером, но сам RAG не выделяется в отдельное приложение.

Файлы запуска будут добавлены после выбора стека backend, чтобы конфигурация была исполняемой, а не фиктивной.
