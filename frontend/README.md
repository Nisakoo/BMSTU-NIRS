# Frontend

Этот каталог предназначен для пользовательского интерфейса проекта
`smeshariki-ai`.

Frontend запускается отдельно и не входит в Docker Compose backend. Конкретный
frontend-стек, зависимости, команды запуска и продуктовые тесты будут выбраны и
добавлены отдельной SDD-спецификацией.

Сейчас каталог содержит только нейтральные папки `src/` и `tests/`.
