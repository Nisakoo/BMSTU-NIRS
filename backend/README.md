# Backend

Backend проекта `smeshariki-ai` развивается как модульный монолит: API, runtime
агента, серверная бизнес-логика и реализация RAG находятся в одном приложении.

Исходный Python-пакет называется `smeshariki_ai` и расположен в `src/`:

- `api/` — FastAPI HTTP/SSE-слой диалогов и встроенная `/agent_test`;
- `agent/` — runtime агента и инструменты;
- `application/` — прикладная оркестрация через `AgentService`;
- `dialogs/` — контракт и in-memory хранилище истории;
- `rag/` — будущая реализация внутреннего инструмента RAG.

Агент и RAG не являются отдельными верхнеуровневыми сервисами. ASGI entrypoint —
`smeshariki_ai.main:app`; стандартный контейнерный запуск выполняется командой
`make run` из корня репозитория. Production bootstrap использует потоковый
LiteLLM-провайдер. История, очередь запросов и SSE-подписки находятся только в
памяти процесса и теряются при рестарте; replay событий не поддерживается.

После запуска `/agent_test` предоставляет один самодостаточный HTML для ручной
проверки агента. Он создаёт диалог через `POST /api/v1/dialogs`, отправляет
сообщения в `POST /api/v1/dialogs/{dialog_id}/messages` и читает поток из
`GET /api/v1/dialogs/{dialog_id}/events`.
