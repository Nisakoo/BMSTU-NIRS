# Backend

Backend проекта `smeshariki-ai` развивается как модульный монолит: API, runtime
агента, серверная бизнес-логика и реализация RAG находятся в одном приложении.

Исходный Python-пакет называется `smeshariki_ai` и расположен в `src/`:

- `api/` — будущий HTTP-слой;
- `agent/` — будущий runtime агента;
- `rag/` — базовый внутренний RAG с System Context и Structured Knowledge.

Агент и RAG не являются отдельными верхнеуровневыми сервисами.

## Базовый RAG

Компонент предоставляет Python-сервис `StructuredKnowledgeService` с двумя
операциями:

- `get_system_context()` возвращает версионируемые инвариантные правила;
- `lookup_knowledge(entity_type, key, canon_variants)` выполняет точный поиск по
  ID, имени или алиасу и возвращает `found`, `not_found` либо `ambiguous`.

Системный контекст хранится в Markdown, а профили персонажей, локаций и
артефактов — в JSON внутри Python-пакета. Источники полностью валидируются при
запуске. Поиск не требует сети или внешней инфраструктуры.

## Локальная проверка

Из корня репозитория выполните:

```sh
make run
```

CLI сообщает о готовности JSON-событием, после чего принимает по одной команде
на строку:

```text
context
lookup character "Пин"
lookup character "Пин" movie
lookup location "мастерская пина"
lookup artifact "Пинолёт"
lookup character неизвестный
exit
```

Ключ нормализуется через удаление крайних пробелов, lower case и замену `ё` на
`е`. Необязательные варианты канона после ключа объединяются по правилу OR.

Полный набор продуктовых тестов:

```sh
make test
```

Управление окружением и зависимостями выполняется `uv` для Python 3.12.
