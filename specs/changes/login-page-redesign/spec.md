# Редизайн страницы входа

## Цель

Сделать страницу `/login/` спокойнее и цельнее по согласованному с пользователем
макету: одна ночная сцена во весь экран вместо отдельного заголовка над сценой,
приветствие внутри карточки формы и сбалансированная левая колонка. Изменение
затрагивает только разметку и стили страницы; поведение формы и контракт API из
[auth-frontend-contract](../auth-frontend-contract/spec.md) не меняются.

## Требования

- REQ-001: Плашка «Добрые истории вместе с ИИ» и крупный заголовок над сценой
  удалены; вся страница — одна ночная сцена со звёздами, луной в правом верхнем
  углу и полянкой, занимающая высоту экрана на desktop.
- REQ-002: В левом верхнем углу сцены находится логотип «✦ Смешарики AI» в стиле
  шапки чата, ведущий на `/`.
- REQ-003: Левая колонка содержит заголовок «Сочиняй истории вместе со
  Смешариками» с розовым акцентом на последнем слове, а под ним — облачко
  «Привет! Заходи, будем сочинять истории!» и групповое изображение Смешариков на
  полянке. Дополнительного поясняющего абзаца нет.
- REQ-004: Карточка формы стеклянная, с тонкой голубо-розовой линией сверху и
  белым заголовком «Заходи в Ромашковую долину»; под ним остаётся подзаголовок
  режима.
- REQ-005: Переключатель «Вход»/«Регистрация» — единая сегментированная дорожка;
  выбранный режим выделен голубой заливкой, что отличимо не только по цвету, но и
  по форме заполненного сегмента.
- REQ-006: Поля логина и пароля имеют подсказки-placeholder «например, krosh» и
  «не меньше 8 символов»; подписи `label` сохраняются.
- REQ-007: На ширине до `860px` колонки выстраиваются вертикально: логотип,
  заголовок, изображение с облачком, карточка; на ширине до `570px` луна
  скрыта. На viewport от `320px` до `1920px` нет горизонтальной прокрутки и
  элементов за краем экрана.
- REQ-008: Идентификаторы элементов, поведение формы, тексты ошибок и тесты
  страницы и клиента `AuthApi` остаются без изменений.

## Сценарии

### Desktop

- Given viewport `1440x900`
- When пользователь открывает `/login/`
- Then слева сверху логотип и заголовок, снизу Смешарики с облачком, справа
  карточка формы, без пустой верхней левой области

### Mobile

- Given viewport `375x800`
- When пользователь открывает `/login/`
- Then логотип, заголовок, Смешарики и карточка идут одной колонкой без
  горизонтальной прокрутки

## Технологии и структура

Меняются только `frontend/src/login/index.html`, `frontend/src/login/login.css`
и описание страницы в `frontend/README.md`. Новых зависимостей и изображений нет.

## Команды

- Frontend-тесты: `npm --prefix frontend test`
- Production-сборка: `npm --prefix frontend run build`
- Полная проверка: `make test`

## Тестирование

| Требования | Способ проверки |
| --- | --- |
| REQ-001–REQ-006 | Визуальное ревью production build в Chrome на `1440x900` и `375x800` |
| REQ-007 | Измерение `scrollWidth` и границ элементов через Chrome DevTools Protocol на `320x568`, `375x800`, `768x1024`, `1440x900`, `1920x1080` |
| REQ-008 | Существующие Node-тесты `login-ui.test.js`, `auth-api.test.js`, proxy smoke и `make test` проходят без изменений тестов |

Новые тесты на этапе `specify` не реализуются.

## Границы

- Всегда: сохранять идентификаторы и поведение формы; держать один розовый
  акцент в тексте и розовую кнопку отправки.
- Сначала спросить: добавлять новые изображения, тексты или декоративные
  элементы.
- Никогда: менять контракт API, логику `login.js` или тесты ради внешнего вида.

## Критерии приёмки

- [ ] Страница соответствует согласованному макету без абзаца про Кроша и
  компанию.
- [ ] На контрольных viewport нет горизонтальной прокрутки.
- [ ] `npm --prefix frontend test`, proxy smoke, production build и `make test`
  проходят успешно.
