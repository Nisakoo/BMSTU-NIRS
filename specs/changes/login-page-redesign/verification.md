## Матрица viewport

Измерено через Chrome DevTools Protocol на production build (`vite preview`).

| Viewport | `scrollWidth` = ширина | Элементы за краем |
| --- | --- | --- |
| `320x568` | Да | Нет |
| `375x800` | Да | Нет |
| `768x1024` | Да | Нет |
| `1440x900` | Да | Нет |

Режим регистрации с ошибками полей дополнительно проверен на `1440x900` и
`375x800`: ошибки переносятся без обрезания и overflow.
