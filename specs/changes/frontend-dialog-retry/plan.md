# План: повторное создание диалога

## Основание

Реализуется `spec.md` этого изменения. Backend и Vite proxy уже возвращают
`201`; застревание происходит в однократной попытке frontend.

## Задача 1. Зафиксировать сбой и восстановление тестами

**Требования:** REQ-001–REQ-004, REQ-006.

**Файлы:** `frontend/tests/ui.test.js`.

**Действия:** добавить управляемые fake-таймеры и падающие тесты повтора,
восстановления, отсутствия повторного запроса после успеха и отмены при
`beforeunload`.

**Проверка:** `npm --prefix frontend test` (RED).

## Задача 2. Исправить lifecycle создания диалога

**Требования:** REQ-001–REQ-005.

**Файлы:** `frontend/src/script.js`, `frontend/tests/ui.test.js`.

**Действия:** запланировать один повтор после ошибки, отменить его при закрытии,
сохранить существующее подключение SSE и блокировку формы до `ready`.

**Проверка:** `npm --prefix frontend test` (GREEN), затем упростить при
сохранении зелёных тестов.

## Задача 3. Обновить документацию и проверить результат

**Требования:** REQ-005–REQ-006.

**Файлы:** `frontend/README.md`, `docs/dialogs.md`, `AGENTS.md`,
`specs/changes/frontend-dialog-retry/verification.md`.

**Проверка:** `make test`, `npm --prefix frontend run build`,
`npm --prefix frontend run test:proxy`, `git diff --check`; ревью границ и
запись результатов без запуска браузера.
