# Подсказка Кроша до выбора способа начать историю

## Цель

Сохранить подсказку рядом с Крошем в ноутбучном и широком интерфейсе и скрывать
её после прямого нажатия пользователя на строку ввода либо выбора типа истории.

## Требования

- REQ-001: На viewport шире `820px` подсказка должна быть видна рядом с Крошем
  после загрузки страницы и подключения диалога.
- REQ-002: Автоматический фокус приложения после события `ready` не должен
  скрывать подсказку.
- REQ-003: Нажатие мышью, трекпадом или касание активной строки ввода должно
  скрывать подсказку до следующей перезагрузки страницы.
- REQ-004: Выбор любой тематической кнопки типа истории должен заполнить строку
  как раньше и скрыть подсказку до следующей перезагрузки страницы.
- REQ-005: Повторные нажатия на textarea после скрытия безопасны и не меняют
  текст, autosize, Enter/Shift+Enter или отправку формы.
- REQ-006: Программное заполнение, клавиатурное событие, вставка, drop или
  успешная отправка сами по себе не должны скрывать подсказку.
- REQ-007: Согласованный мобильный режим до `820px` остаётся без декоративных
  рисунков, Кроша и подсказки.
- REQ-008: Реализация остаётся на vanilla JavaScript и CSS; сетевые контракты,
  адаптивная геометрия и backend не меняются.
- REQ-009: Frontend-документация и архитектурный каталог должны описывать
  фактическое правило скрытия подсказки.

## Сценарии

### Нажатие на строку ввода

- Given desktop-интерфейс загружен и подсказка видна рядом с Крошем
- When пользователь нажимает мышью, трекпадом или касается textarea
- Then подсказка скрывается до перезагрузки
- And содержимое textarea и состояние формы не меняются

### Автоматический фокус

- Given диалог подключился и приложение программно фокусирует textarea
- When событие `ready` обработано
- Then подсказка остаётся видимой

### Тематическая кнопка

- Given подсказка видна и пользователь не нажимал textarea
- When пользователь выбирает тематическую кнопку
- Then строка заполняется выбранным шаблоном и подсказка скрывается

### Клавиатурные события

- Given подсказка видна и пользователь не нажимал textarea или тематическую
  кнопку
- When textarea получает keyboard/input/paste/drop событие без pointer/touch
- Then подсказка остаётся видимой

### Мобильный экран

- Given viewport не шире `820px`
- When frontend отрисовывается
- Then Крош и подсказка скрыты вместе с остальной декоративной сценой

## Технологии и структура

- `frontend/src/script.js`: вызывать идемпотентное скрытие подсказки на прямых
  `pointerdown`/`touchstart` событиях textarea и при выборе тематической кнопки;
  удалить скрытие из остальных действий.
- `frontend/tests/ui.test.js`: изменить поведенческие тесты так, чтобы они
  различали нажатие на textarea и другие события.
- `frontend/README.md` и `docs/README.md`: актуализировать описание поведения.

## Команды

- Запуск: `make run`
- Тесты: `make test`
- Frontend-тесты: `npm --prefix frontend test`
- Production-сборка: `npm --prefix frontend run build`

## Тестирование

| Требования | Способ проверки |
| --- | --- |
| REQ-001–REQ-004 | Node DOM-тесты автоматического фокуса, pointer/touch-нажатия и тематической кнопки; browser runtime на desktop |
| REQ-005–REQ-006 | Node DOM-тесты focus, keydown, input, paste, drop, повторного нажатия, autosize и отправки |
| REQ-007 | Существующая browser viewport-проверка mobile `display: none` |
| REQ-008 | Ревью diff, frontend-тесты и Vite production build |
| REQ-009 | Ревью документации без искусственных структурных тестов |

Новые тесты на этапе `specify` не реализуются.

## Границы

- Всегда: сохранять подсказку рядом с Крошем на desktop и мобильный режим без
  рисунков; проверять mouse/pointer, touch и тематические кнопки.
- Сначала спросить: менять текст или оформление подсказки; возвращать Кроша и
  подсказку на mobile.
- Никогда: скрывать подсказку от автоматического фокуса; менять backend или
  сетевой поток ради этого поведения.

## Критерии приёмки

- [ ] Подсказка видна рядом с Крошем после desktop-загрузки и автоматического
  фокуса.
- [ ] Pointer/touch-нажатие на textarea скрывает подсказку идемпотентно.
- [ ] Выбор тематической кнопки заполняет textarea и скрывает подсказку.
- [ ] Непоинтерные события textarea и отправка сами по себе не скрывают
  подсказку.
- [ ] До `820px` mobile остаётся без декоративной сцены и подсказки.
- [ ] `make test` и `npm --prefix frontend run build` проходят успешно.
- [ ] Документация соответствует реализации.

## Открытые вопросы

- Нет. Подсказку скрывает прямое pointer/touch-нажатие на textarea или выбор
  тематической кнопки, но не любое событие ввода или программный фокус.
