# План: подсказка Кроша до выбора способа начать историю

## Исходное состояние и решение

- Подсказка уже находится рядом с Крошем и видна на desktop; mobile CSS
  намеренно скрывает её вместе с декоративной сценой.
- Сейчас JavaScript скрывает подсказку от focus, pointer, touch, keyboard,
  input, paste, drop, тематической кнопки и отправки. Это шире нового правила.
- Оставляем идемпотентный `dismissHint()` и вызываем его из прямых
  `pointerdown`/`touchstart` обработчиков textarea и обработчика тематических
  кнопок.
- Автоматический focus больше не требует специального флага подавления, потому
  что focus сам по себе не будет скрывать подсказку.

## Риски и контроль

- **Touch вызывает и touchstart, и pointerdown.** `dismissHint()` идемпотентен;
  повторное событие покрывается тестом.
- **Preset фокусирует textarea и случайно скрывает подсказку.** Focus больше не
  привязан к скрытию, отдельный тест проверяет этот сценарий.
- **Mobile-regression возвращает подсказку без Кроша.** CSS не меняется;
  computed-style проверяется на двух мобильных viewport.
