# Возврат из чата в панель администратора

## Цель

В боковой панели `/admin/` есть ссылка «Открыть пользовательский чат»
(позже сокращена до «Пользовательский чат»), а в
чате обратного пути нет: администратор может вернуться в панель, только
набрав `/admin/` вручную. Изменение добавляет в боковую панель чата ссылку
«Панель администратора» для пользователей с ролью `admin`.

## Требования

- REQ-001: В боковой панели чата над строкой с логином и «Выйти» есть
  ссылка «Панель администратора» на `/admin/`; она видна только после
  проверки сессии и только для роли `admin`.
- REQ-002: Пользователь с ролью `user` ссылку не видит; в разметке она
  скрыта (`hidden`) до проверки сессии. Доступ к `/admin/` по-прежнему
  проверяют страница и backend.
- REQ-003: На телефоне ссылка видна в выезжающей панели «Истории»; нет
  горизонтальной прокрутки.

## Технологии и структура

- `frontend/src/index.html`: ссылка `#saiAdminLink` с `hidden`.
- `frontend/src/script.js`: показ по роли после проверки сессии.
- `frontend/src/styles.css`: стиль ссылки.
- Документация: `frontend/README.md`, `AGENTS.md`.

## Тестирование

- UI-тесты: ссылка видна администратору, скрыта для пользователя и до
  проверки сессии, ведёт на `/admin/`.
- Ручная проверка через CDP: администратор переходит чат → панель → чат →
  панель; пользователь ссылки не видит; 1280 и 390 px.

## Критерии приёмки

- [ ] Администратор возвращается из чата в панель одной ссылкой.
- [ ] Обычный пользователь ссылки не видит.
- [ ] `make test` проходит; Python-код не меняется.

## Открытые вопросы

- Нет. Изменение исправляет описанную пользователем проблему.
