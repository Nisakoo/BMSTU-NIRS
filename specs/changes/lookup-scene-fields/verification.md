# Проверка: точечные поля lookup_knowledge

## Результат

`lookup_knowledge` принимает необязательный `fields`. Без него поведение
прежнее; с ним карточка персонажа содержит только запрошенные части.
Инструмент остаётся точным фактическим поиском.

## Требования

| Требование | Проверка | Результат |
| --- | --- | --- |
| REQ-001–REQ-002 | `pytest backend/tests/unit/rag/test_lookup.py` | Пройдено |
| REQ-003 | Тест полной карточки без `fields` | Пройдено |
| REQ-004 | Локации, артефакты и эпизоды не затронуты | Существующие тесты |
| REQ-005 | `ToolRegistry`: неверные аргументы | Пройдено |
| REQ-006 | Ревью `rag/tools.py` и `agent/prompts/system.md` | Пройдено |

## Команды

```text
uv run --project backend --locked --no-sync pytest -q backend/tests/unit/rag
361 passed
```

## Ограничения

- `fields` действует только на карточку персонажа; для локаций, артефактов и
  эпизодов карточка остаётся полной.
- Пустой `fields` отклоняется валидацией аргументов.
