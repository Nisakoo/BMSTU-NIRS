# План: Крош в пустом чате

Спецификация: [spec.md](./spec.md).

## Порядок

Сначала рискованная часть — попадание изображения в production build: блок
описывается статической разметкой `<template>` в `index.html` со ссылкой на
`static/characters/krosh.png`, чтобы Vite обработал её как ассет. Затем
поведение в `script.js` по TDD и стили. Визуальная проверка и описание —
последними.

## Задача 1. Поведение блока

**Требования:** REQ-001…REQ-004, REQ-007.

**Решение:** `showStory` для пустой истории клонирует шаблон `#saiKroshTemplate`
в ленту вместо текстового приветствия; первое принятое сообщение пользователя
удаляет блок перед добавлением реплики. Текст облачка — статическая разметка
шаблона, динамический текст не вставляется.

**Критерии приёмки:** UI-тесты: блок виден в новой истории; исчезает после
`202` первого сообщения; остаётся при ошибке отправки; отсутствует при
открытии истории с сообщениями; есть у пустой сохранённой истории;
возвращается после «+ Новая история»; прежние тесты проходят.

**Файлы:** `frontend/src/index.html`, `frontend/src/script.js`,
`frontend/tests/ui.test.js`.

**Проверка:** `npm --prefix frontend test`.

## Задача 2. Стили и сборка

**Требования:** REQ-005, REQ-006.

**Критерии приёмки:** блок по центру ленты, облачко с хвостиком к Крошу,
покачивание отключается при `prefers-reduced-motion`; на узких экранах Крош
уменьшается; изображение есть в `frontend/dist` и отдаётся через Caddy с
`200`.

**Файлы:** `frontend/src/styles.css`.

**Проверка:** `npm --prefix frontend run build`; пересборка frontend в
Compose; `curl` изображения; скриншоты и замер прокрутки на шести viewport.
