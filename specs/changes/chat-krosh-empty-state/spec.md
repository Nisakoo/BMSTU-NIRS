# Крош в пустом чате

## Цель

После перехода чата на раскладку с боковой панелью
([chat-sidebar-layout](../chat-sidebar-layout/spec.md)) у новой истории
пустая лента выглядит безлико: одно текстовое приветствие и много пустого
места. По согласованному с командой макету в пустой новой истории в центре
ленты стоит Крош с приветственным облачком, а с началом разговора он
исчезает. Изменение только визуальное и затрагивает frontend; сетевой
протокол и API не меняются.

## Требования

- REQ-001: В новой истории без сообщений вместо текстового приветствия
  ассистента лента показывает по центру изображение Кроша, облачко с текстом
  «Ёлки-иголки, привет! Я Крош. Давай сочиним что-нибудь такое, чтобы даже
  Кар-Карыч удивился! Кого берём в историю и куда отправимся?» (первые слова
  выделены розовым) и подпись «Напиши идею или выбери тему ниже».
- REQ-002: Блок с Крошем исчезает в момент, когда первое сообщение
  пользователя принято (`202 Accepted`) и добавлено в ленту. Если отправка не
  удалась, блок остаётся вместе с черновиком в поле ввода.
- REQ-003: При открытии сохранённой истории из списка блок не показывается —
  сразу отображаются её сообщения. Сохранённая история без сообщений
  показывает блок с Крошем.
- REQ-004: «+ Новая история» и перезагрузка страницы снова показывают блок с
  Крошем.
- REQ-005: Изображение Кроша попадает в production build Vite и загружается
  без ошибок через Caddy/Nginx; имеет `alt="Крош"`, текст облачка доступен
  экранным читалкам. При `prefers-reduced-motion: reduce` лёгкое покачивание
  Кроша отключается.
- REQ-006: Блок не создаёт прокрутки страницы и не выходит за край: на
  viewport от `320px` до `1920px` нет горизонтальной прокрутки, а на `1280x720`
  и больше страница целиком не прокручивается. На узких экранах размер Кроша
  уменьшается так, чтобы блок помещался над полем ввода.
- REQ-007: Остальное поведение чата из
  [chat-sidebar-layout](../chat-sidebar-layout/spec.md) не меняется:
  блокировка формы до `ready`, буферизация событий, переключение историй,
  список, ошибки и выход.

## Сценарии

### Начало истории

- Given открыта новая история
- When пользователь отправляет первый запрос и backend отвечает `202`
- Then Крош исчезает, в ленте появляется сообщение пользователя, затем ответ
  агента

### Неудачная отправка

- Given открыта новая история
- When отправка первого запроса завершается ошибкой
- Then Крош остаётся, черновик сохранён в поле ввода

### Сохранённая история

- Given у пользователя есть история с сообщениями
- When он открывает её из списка
- Then Кроша нет, показаны сообщения истории

### Возврат к новой истории

- Given открыта история с сообщениями
- When пользователь нажимает «+ Новая история»
- Then снова показан Крош с облачком

## Технологии и структура

Vanilla JavaScript и CSS без новых зависимостей. Меняются
`frontend/src/index.html` (шаблон блока и ссылка на изображение, чтобы Vite
включил его в сборку), `frontend/src/styles.css`, `frontend/src/script.js`,
`frontend/tests/ui.test.js`, описание в `frontend/README.md` и `AGENTS.md`.
Используется существующий файл `frontend/src/static/characters/krosh.png`.

## Команды

- Запуск: `make run`
- Тесты: `make test`
- Сборка: `npm --prefix frontend run build`

## Тестирование

- Node-тесты UI на fake DOM: Крош виден в новой истории; скрывается после
  `202` первого сообщения; остаётся при ошибке отправки; не показывается при
  открытии истории с сообщениями; показывается для пустой сохранённой
  истории; возвращается после «+ Новая история».
- Сборка: изображение Кроша присутствует в `frontend/dist`, а через Caddy
  отдаётся с кодом `200`.
- Визуальная проверка скриншотами headless Chrome на `1920x1080`, `1440x900`,
  `1280x720`, `768x1024`, `375x800`, `320x640` с замером прокрутки.

## Границы

- Всегда: вставлять текст облачка как статическую разметку или через
  `textContent`; сохранять поведение чата.
- Сначала спросить: других персонажей, смену текста приветствия, аватар Кроша
  у ответов ассистента.
- Никогда: не менять backend и API, не возвращать плавающий пузырь Кроша
  поверх сцены.

## Критерии приёмки

- [ ] В новой истории на `1440x900` Крош с облачком по центру ленты, как на
  согласованном макете.
- [ ] После принятия первого сообщения Крош исчезает; при ошибке отправки
  остаётся.
- [ ] Сохранённая история с сообщениями открывается без Кроша.
- [ ] Изображение загружается из production build.
- [ ] На проверяемых viewport нет горизонтальной прокрутки, на `1280x720` и
  больше нет вертикальной прокрутки страницы.
- [ ] `make test` проходит успешно.

## Открытые вопросы

- Нет. Допущение: текстовое приветствие ассистента («Привет! Давай придумаем
  историю вместе…») заменяется облачком Кроша, а не показывается вместе с ним.
