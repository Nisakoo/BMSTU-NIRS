# Крош в пустом чате

## Цель

После перехода чата на раскладку с боковой панелью ([chat-sidebar-layout](../chat-sidebar-layout/spec.md)) у новой истории пустая лента выглядит безлико: одно текстовое приветствие и много пустого
места. По согласованному с командой макету в пустой новой истории в центре ленты стоит Крош с приветственным облачком, а с началом разговора он исчезает. Изменение только визуальное и затрагивает frontend; сетевой
протокол и API не меняются.

## Требования

- REQ-001: В новой истории без сообщений вместо текстового приветствия ассистента лента показывает по центру изображение Кроша, облачко с текстом «Ёлки-иголки, привет! Я Крош. Давай сочиним что-нибудь такое, чтобы даже
  Кар-Карыч удивился! Кого берём в историю и куда отправимся?» (первые слова выделены розовым) и подпись «Напиши идею или выбери тему ниже».
- REQ-002: При отправке первого сообщения место Кроша занимает индикатор ожидания. После `202 Accepted` в ленте появляется текст пользователя. При ошибке POST в пустой ленте снова виден Крош.
- REQ-003: При открытии сохранённой истории из списка блок не показывается — сразу отображаются её сообщения. Сохранённая история без сообщений показывает блок с Крошем.
- REQ-004: «+ Новая история» показывает блок с Крошем. После F5 блок виден у пустого диалога; восстановленный диалог с сообщениями показывает историю.
- REQ-005: Изображение Кроша попадает в production build Vite и загружается без ошибок через Caddy/Nginx; имеет `alt="Крош"`, текст облачка доступен
  экранным читалкам. При `prefers-reduced-motion: reduce` лёгкое покачивание Кроша отключается.
- REQ-006: Блок не создаёт прокрутки страницы и не выходит за край: на viewport от `320px` до `1920px` нет горизонтальной прокрутки, а на `1280x720`
  и больше страница целиком не прокручивается. На узких экранах размер Кроша уменьшается так, чтобы блок помещался над полем ввода.
- REQ-007: Остальное поведение чата из [chat-sidebar-layout](../chat-sidebar-layout/spec.md) не меняется: блокировка формы до `ready`, буферизация событий, переключение историй, список, ошибки и выход.

## Границы

- Всегда: вставлять текст облачка как статическую разметку или через
  `textContent`; сохранять поведение чата.
- Сначала спросить: других персонажей, смену текста приветствия, аватар Кроша у ответов ассистента.
- Никогда: не менять backend и API, не возвращать плавающий пузырь Кроша поверх сцены.
