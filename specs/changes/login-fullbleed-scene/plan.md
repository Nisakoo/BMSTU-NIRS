# План: страница входа без внешней рамки

Спецификация: [spec.md](./spec.md).

## Порядок

Изменение только визуальное: сначала разметка и стили, затем скриншоты на
контрольных viewport, затем описание.

## Задача 1. Разметка и стили

**Требования:** REQ-001…REQ-007.

**Критерии приёмки:** `.auth` без внешних отступов, `.auth-scene` без рамки,
скругления и тени, высотой `100vh` (`100dvh`) на desktop; облачко удалено;
карточка по центру справа; мобильные правила `860px`/`570px` сохраняют одну
колонку на фоне сцены во всю ширину.

**Файлы:** `frontend/src/login/index.html`, `frontend/src/login/login.css`.

**Проверка:** `npm --prefix frontend test` (поведение не изменилось).

## Задача 2. Визуальная проверка

**Требования:** REQ-002, REQ-006, критерии приёмки.

**Проверка:** скриншоты headless Chrome `1440x900`, `1280x720`, `768x1024`,
`375x800`, `320x640` из `make run`; проверка `scrollWidth <= clientWidth`
через headless Chrome.

## Задача 3. Описание

**Файлы:** `frontend/README.md`, `docs/auth.md` (если описывает облачко или
рамку).

**Проверка:** ревью; `make test`.
