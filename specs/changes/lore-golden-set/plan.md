# План: golden set лора

1. Собрать `data/lore-golden/lore` из полного `data/lore` (84 документа).
2. Зафиксировать 20 обычных вопросов и 10 ловушек с тремя релевантными
   документами у обычных вопросов.
3. Подготовить `answers.json` только для офлайн-проверки.
4. Один раз запустить `lore-benchmark` с `k=5`.
5. Записать метрики и ограничения в `verification.md`.

Итог: метрики без подгонки формулировок.
