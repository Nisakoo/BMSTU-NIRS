# Проверка: адаптивный frontend и скрытие подсказки Кроша

## Итог

Изменение успешно прошло verify 2026-09-27. Frontend плавно масштабируется от
мобильных до широких viewport, не создаёт горизонтальную прокрутку страницы и
не допускает пересечения формы с Крошем, Копатычем или подсказкой. Подсказка
скрывается после первого пользовательского взаимодействия со строкой ввода или
тематической кнопкой, но остаётся видимой после автоматического фокуса.

## Матрица viewport

Измерения выполнены в установленном Google Chrome через локальный DevTools
Protocol при запущенном Vite dev server.

| Viewport | Ширина сцены | Ширина чата | Горизонтальный overflow | Контролы внутри viewport | Пересечение формы с декором |
| --- | ---: | ---: | --- | --- | --- |
| `320x568` | `306px` | `288px` | Нет | Да | Нет |
| `375x667` | `361px` | `343px` | Нет | Да | Нет |
| `768x1024` | `750px` | `724px` | Нет | Да | Нет |
| `1366x768` | `1298px` | `1120px` | Нет | Да | Нет |
| `1440x900` | `1368px` | `1120px` | Нет | Да | Нет |
| `1920x1080` | `1600px` | `1120px` | Нет | Да | Нет |

Минимальный измеренный вертикальный зазор между composer и декором положителен
на всех viewport. На desktop минимальный зазор составил `34.7px`, на mobile —
`49.3px`.

## Известные ограничения

- Runtime-снимки выполнялись с Vite без запущенного backend, поэтому статус
  показывал предусмотренное состояние повторного подключения. Геометрию это не
  меняет; HTTP/SSE-поведение отдельно покрыто успешными Node- и backend-
  тестами.
