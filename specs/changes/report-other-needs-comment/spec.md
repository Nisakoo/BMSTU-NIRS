# Комментарий обязателен для причины «Другое»

## Цель

В [message-report](../message-report/spec.md) комментарий к жалобе всегда
необязателен. Для причин «Страшно», «Грубо или обидно» и «Неправильно или
непонятно» причина говорит сама за себя, а жалоба «Другое» без
комментария не объясняет администратору, что не так. Пользователь просит
сделать комментарий обязательным только для «Другое».

## Требования

- REQ-001: При причине «Другое» «Отправить» недоступна, пока комментарий
  пуст или состоит из пробелов; ввод текста сразу делает кнопку доступной.
- REQ-002: При «Другое» поле комментария помечено обязательным
  (`aria-required="true"`, подсказка «Расскажи, что не так (обязательно)»);
  при остальных причинах — необязательным (`aria-required="false"`,
  подсказка «… (необязательно)»). Смена причины сразу меняет пометку и
  доступность кнопки; введённый текст сохраняется.
- REQ-003: `POST …/report` с `reason: "other"` и отсутствующим или пустым
  после обрезки комментарием отвечает `422`; жалоба не создаётся. Для
  остальных причин комментарий по-прежнему необязателен.
- REQ-004: Остальное поведение жалобы не меняется.

## Технологии и структура

- `backend/src/smeshariki_ai/api/schemas.py`: проверка `ReportRequest`.
- `frontend/src/script.js`: доступность кнопки и пометка поля.
- Документация: `docs/dialogs.md`, `frontend/README.md`.

## Тестирование

- API-тесты: «Другое» без комментария и с пробелами — `422`, с
  комментарием — `201`; остальные причины без комментария — `201`.
- UI-тесты: доступность «Отправить» и пометка поля при «Другое» и смене
  причины, ввод текста.
- Ручная проверка через CDP.

## Критерии приёмки

- [ ] Жалобу «Другое» нельзя отправить без комментария ни из интерфейса, ни
  через API.
- [ ] Для остальных причин комментарий необязателен.
- [ ] `make test` и `make lint` проходят.
