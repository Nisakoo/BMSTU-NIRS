# Приветствие администратора по времени суток

## Цель

Заголовок панели `/admin/` всегда «Добрый вечер, администратор»: текст
вписан в разметку и не зависит ни от времени, ни от того, кто вошёл.
Изменение строит приветствие по местному времени браузера и логину
вошедшего администратора.

## Требования

- REQ-001: Приветствие зависит от местного часа при открытии панели:
  5:00–11:59 — «Доброе утро», 12:00–16:59 — «Добрый день», 17:00–22:59 —
  «Добрый вечер», 23:00–4:59 — «Доброй ночи».
- REQ-002: Заголовок — «<приветствие>, <логин>», логин берётся из проверки
  сессии и выводится только как текст.
- REQ-003: До проверки сессии в разметке нейтральный текст «Здравствуйте»,
  без неверного времени суток. Гость и пользователь с ролью `user`
  перенаправляются как раньше.

## Технологии и структура

- `frontend/src/admin/index.html`: `id="adminGreeting"` и нейтральный текст.
- `frontend/src/admin/admin.js`: функция приветствия и подстановка после
  проверки роли.
- `frontend/README.md`, `AGENTS.md`.

## Тестирование

- UI-тесты: границы всех четырёх промежутков (4:59, 5:00, 11:59, 12:00,
  16:59, 17:00, 22:59, 23:00); заголовок с логином после входа
  администратора; логин с HTML выводится как текст.
- Ручная проверка через CDP на `make run`.

## Критерии приёмки

- [ ] Заголовок панели меняется по времени суток и содержит логин.
- [ ] `make test` проходит; Python-код не меняется.
