# «Настройки» со сменой пароля в админке

## Цель

В чате есть кнопка «Настройки» с окном смены пароля
([change-password](../change-password/spec.md),
[settings-above-divider](../settings-above-divider/spec.md)), а в `/admin/`
её нет. Изменение добавляет такую же кнопку и окно в панель администратора.
Backend-контракт `PUT /api/v1/users/me/password` не меняется.

## Требования

- REQ-001: В нижней части боковой панели `/admin/`, между ссылкой
  «Пользовательский чат» и «Выйти», есть кнопка «Настройки» со значком
  шестерёнки (значок декоративный). Она в стиле кнопки «Выйти» панели.
  На узких экранах (≤ 820px) она стоит рядом с «Выйти» в правом верхнем углу.
- REQ-002: Кнопка открывает модальное окно с тем же содержанием и поведением,
  что в чате: заголовок «Настройки», раздел «Сменить пароль», три поля,
  «Сохранить»; локальные проверки, сообщения для `204`/`400`/`422`/`503`,
  блокировка на время запроса, закрытие кнопкой, `Escape` и щелчком по фону
  с возвратом фокуса, очистка полей. Оформление — в стиле админки.
- REQ-003: При `401` админка выполняет один `POST /auth/refresh` и повторяет
  запрос; если сессии нет — переходит на `/login/`.
- REQ-004: Логика окна общая для чата и админки (один модуль), поведение
  чата не меняется.
- REQ-005: Окно подключается только после проверки роли `admin`, как
  кнопка «Выйти».

## Технологии и структура

- `frontend/src/password-settings.js` — общий модуль окна (перенос логики из
  `script.js`);
- `frontend/src/script.js` — использует модуль;
- `frontend/src/admin/index.html`, `admin.js`, `admin.css` — кнопка, окно,
  подключение;
- документация: `docs/auth.md`, `docs/admin.md`, `frontend/README.md`,
  `AGENTS.md`.

## Тестирование

- Существующие UI-тесты окна в чате проходят без изменений.
- Новые тесты `admin-ui.test.js`: открытие и закрытие, локальная ошибка без
  запроса, успешная смена, неверный пароль, refresh и повтор на `401`,
  переход на `/login/` без сессии, окно не подключается до проверки роли.
- Скриншоты админки с кнопкой и открытым окном.

- [ ] `npm --prefix frontend test` проходит.
