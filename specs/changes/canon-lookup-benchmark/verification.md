# Проверка: бенчмарк точного поиска по канону

Исторический оригинал: `git show 5af56b5:specs/changes/canon-lookup-benchmark/verification.md`.

## Результат

- Добавлена команда `knowledge-benchmark`: офлайн-оценка `lookup_knowledge` на пакете знаний через `InMemoryKnowledgeStore`. Собран golden set из реального канона. Заполнены пустые списки `characters` в лоре.
- Порог `pg_trgm` не настраивался: короткие опечатки (3–4 символа) остаются без подсказки — это кандидат в отдельное изменение;
- разметка канона точная (имя → id), в отличие от тематической разметки лора, поэтому метрики канона следует читать как абсолютные.
