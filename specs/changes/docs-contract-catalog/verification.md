# Проверка каталога архитектуры и контрактов

## Результат

Изменение соответствует `spec.md`. Создан многостраничный каталог с глобальной
картой и отдельными страницами агента и диалогового слоя. Содержание ограничено
архитектурой, пояснениями фактической реализации и краткими контрактами; полные
SDD-требования, сценарии и планы не скопированы.

## Критерии приёмки

- Из корневого README каталог открывается одним переходом.
- Глобальная карта и тематические страницы дают двустороннюю навигацию.
- Контракты сверены с фактическими Python-интерфейсами и маршрутами FastAPI.
- Состояния компонентов сверены с `specs/status.yaml` и существующими
  verification-файлами.
- Все локальные Markdown-ссылки ведут на существующие файлы или каталоги.
- Нереализованные возможности не обозначены как готовые.
- Структурные тесты документации не создавались.

## Выполненные проверки

```sh
git diff --check
rg -n -o '\]\([^)]+' README.md docs/*.md
rg -n '^```mermaid|^flowchart|^sequenceDiagram|^```$' docs/*.md
make test
```

Относительные ссылки дополнительно проверены относительно каталога каждого
Markdown-файла; отсутствующие цели не найдены. `git diff --check` завершился без
ошибок.

Полная продуктовая регрессия:

```text
collected 54 items
54 passed in 0.34s
```

## Ограничения проверки

- Корректность и уместность документации подтверждены ручным ревью, а не
  структурными автотестами, как требует спецификация.
- Mermaid-блоки проверены по синтаксической структуре и содержанию без
  добавления генератора документации или CLI-зависимости.
- Изменение не затрагивает Python-код продукта и не требует отдельной runtime-
  или контейнерной smoke-проверки.
