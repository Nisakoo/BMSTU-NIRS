# План: единый контейнерный запуск с Caddy и Nginx

Основание: [spec.md](./spec.md). Изменение не затрагивает Python-код продукта.
Существующие незакоммиченные изменения сохраняются; браузер не запускается.

## Задача 1. Контейнерная сборка frontend

- Требования: REQ-001, REQ-002, REQ-006.
- Критерий: отдельный образ собирает Vite bundle из зафиксированных npm-
  зависимостей и раздаёт его Nginx; секреты и лишние каталоги не попадают в
  build context.
- Файлы: `.dockerignore`, `docker/frontend.Dockerfile`, при необходимости
  `docker/nginx.conf`.
- Зависимости: нет.
- Проверка: `docker build -f docker/frontend.Dockerfile .` и HTTP-запрос к
  временному контейнеру; ревью содержимого build context. Сначала проверить
  существующее исключение `frontend/` в `.dockerignore`.

## Задача 2. Единая маршрутизация и lifecycle

- Требования: REQ-001, REQ-003–REQ-006.
- Критерий: Compose описывает `backend`, `frontend`, `caddy`; только Caddy
  публикует на хосте HTTP-порт 8080 по умолчанию; `/api` сохраняет префикс и
  проксируется в backend, остальное — в Nginx. Старт учитывает готовность
  сервисов, локальная конфигурация LLM остаётся только у backend.
- Файлы: `docker/compose.yaml`, `docker/Caddyfile`, `docker/.env.example`.
- Зависимости: задача 1.
- Проверка: `docker compose ... config`, запуск стека на свободном тестовом
  порту и HTTP/SSE smoke через Caddy. Отдельно проверить API при остановленном
  backend и после восстановления, а также опубликованные порты.

## Задача 3. Команда запуска и пользовательская документация

- Требования: REQ-001, REQ-006, REQ-007.
- Критерий: `make run` запускает весь стек одной командой; инструкции в корне,
  `docker/` и `frontend/` описывают актуальный адрес, конфигурацию и отдельно
  необязательный Vite dev-режим.
- Файлы: `Makefile`, `README.md`, `docker/README.md`, `frontend/README.md`.
- Зависимости: задача 2.
- Проверка: ревью команд и адресов, пробный запуск `make run` без браузера,
  `make test` для регрессии поведения продукта.

## Задача 4. Архитектурный каталог и правила проекта

- Требования: REQ-003, REQ-004, REQ-007.
- Критерий: глобальная карта, контракт frontend/API и правила запуска отражают
  Caddy → Nginx/backend, сохраняя Vite как dev-вариант и прежний HTTP/SSE API.
- Файлы: `AGENTS.md`, `docs/README.md`, `docs/dialogs.md`.
- Зависимости: задачи 2–3.
- Проверка: ревью ссылок и схемы маршрутов; без искусственных тестов
  структуры документации.

## Задача 5. Итоговая проверка

- Требования: REQ-001–REQ-007.
- Критерий: каждый критерий `spec.md` сопоставлен с наблюдаемым результатом;
  ограничения и непроверенные внешние зависимости явно записаны.
- Файлы: `specs/changes/compose-caddy-nginx-stack/verification.md`.
- Зависимости: задачи 1–4.
- Проверка: `make test`, frontend build, Compose config, чистый тестовый Compose
  запуск, HTTP/SSE smoke через Caddy, `git diff --check`, ревью отсутствия
  секретов в diff. После успешного verify — статус `done` через CLI.
