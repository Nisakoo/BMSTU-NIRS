# Навигация админки следит за прокруткой

## Цель

В `/admin/` пункт боковой навигации выделяется только после щелчка
([admin-active-navigation](../admin-active-navigation/spec.md)). Если
администратор просто прокручивает страницу, выделенным остаётся старый пункт.
Изменение делает так, чтобы при прокрутке выделялся раздел, который сейчас
на экране.

## Требования

- REQ-001: При прокрутке страницы `aria-current="location"` (и подсветка)
  переходит к пункту раздела, который сейчас читается. Текущим считается
  последний по порядку видимый раздел из навигации («Обзор», «Активность»,
  «Пользователи», «Жалобы»), верх которого поднялся до линии на 35 % высоты
  окна или выше. Если ни один не поднялся — «Обзор».
- REQ-002: Когда страница прокручена до самого низа, выделяется последний
  видимый раздел («Жалобы»), даже если его верх не дошёл до линии.
- REQ-003: Щелчок по пункту сразу выделяет его, как раньше, и плавная
  прокрутка к разделу не перебивает выбор: выделение по прокрутке
  возобновляется после её окончания (`scrollend`, а без него — через 1 с).
  То же для смены hash кнопками браузера.
- REQ-004: Пока данные не загружены и разделы скрыты (нулевой размер),
  прокрутка не меняет выделение.
- REQ-005: Пересчёт выполняется не чаще одного раза за кадр
  (`requestAnimationFrame`). URL hash при прокрутке не меняется.
- REQ-006: Прежнее поведение сохраняется: «Обзор» по умолчанию, выбор по
  hash при открытии, неизвестный hash — «Обзор».

## Сценарии

### Прокрутка вниз

- Given открыт `/admin/`, выделен «Обзор»
- When администратор прокручивает до таблицы пользователей
- Then выделен «Пользователи»

### Конец страницы

- Given раздел «Жалобы» короткий
- When страница прокручена до низа
- Then выделены «Жалобы»

### Щелчок по пункту

- Given выделен «Обзор»
- When администратор щёлкает «Пользователи», и страница плавно едет вниз
- Then всё время выделены «Пользователи», в том числе если внизу страница
  упёрлась в конец раньше

## Технологии и структура

- `frontend/src/admin/admin.js`: `mountAdminNavigation` — обработчики
  `scroll`, `scrollend`, `resize`.
- Документация: `frontend/README.md`, `AGENTS.md` (пункт про навигацию
  `/admin/`).

## Тестирование

- Node-тесты `admin-ui.test.js` с поддельными `window` и разделами
  (`getBoundingClientRect`, `innerHeight`, `scrollY`, высота документа):
  смена пункта при прокрутке, конец страницы, скрытые разделы, щелчок не
  перебивается до `scrollend` и таймаута, один пересчёт за кадр.
- Ручная проверка в запущенном стеке.

## Границы

- Никогда: менять URL при прокрутке, разметку разделов и стили навигации.

## Критерии приёмки

- [ ] При прокрутке выделяется раздел на экране; внизу — «Жалобы».
- [ ] Щелчок по пункту не перебивается плавной прокруткой.
- [ ] `npm --prefix frontend test` проходит.
