# Кнопка времени не выделяется при открытой панели

## Цель

В [chat-rect-buttons](../chat-rect-buttons/spec.md) (REQ-004) открытая
кнопка времени получила яркое выделение: подложку, голубую рамку и белый
текст. Пользователь посмотрел и решил иначе: при открытой панели кнопка
должна быть такой же, как строка ввода. Подложка появляется только при
наведении курсора. Открытую панель и так видно над полем.

## Требования

- REQ-001: При открытой панели (`aria-expanded="true"`), когда курсор не
  над кнопкой, у кнопки нет ни фона, ни рамки. Цвета текста и значка такие
  же, как в покое. Кнопка выглядит частью строки ввода.
- REQ-002: При наведении мягкая подложка `rgba(98,208,255,.13)`
  появляется в любом состоянии панели — и при закрытой, и при открытой.
- REQ-003: При фокусе с клавиатуры (`:focus-visible`) подложка остаётся,
  чтобы было видно, где фокус. Например, после закрытия по `Escape`.
- REQ-004: Не меняются: короткое уменьшение при нажатии (`:active`),
  скругление 14px, размеры и поведение панели.

## Сценарии

### Открытая панель

- Given панель длины открыта, курсор над ползунком
- When пользователь смотрит на строку ввода
- Then кнопка «🕒 2 мин» без фона и рамки, в цвет строки ввода; цветная
  только «Отправить»

## Технологии и структура

- `frontend/src/styles.css`: удалить правила открытого состояния
  `.sai-length-button[aria-expanded="true"]`.

## Команды

- Тесты: `make test`
- Сборка: `npm --prefix frontend run build`

## Тестирование

- Существующие Node-тесты проходят без изменений.
- CDP настоящими событиями мыши, по шагам: покой, наведение, клик, увод
  курсора на ползунок, повторный клик, увод курсора. Для каждого шага —
  фон, рамка и цвет текста кнопки. Скриншоты.

## Границы

- Всегда: менять только оформление кнопки времени.
- Никогда: менять поведение панели.

## Критерии приёмки

- [ ] При открытой панели и курсоре не над кнопкой кнопка совпадает с
  покоем (прозрачные фон и рамка).
- [ ] Наведение по-прежнему даёт мягкую подложку.
- [ ] `make test` проходит.
