# Проверка: реранкинг кандидатов лора через LLM

Исторический оригинал: `git show 5af56b5:specs/changes/lore-llm-rerank/verification.md`.

## Результат

- Добавлены порт `Ranker`, `NoopRanker` и `LLMReranker`, дедупликация кандидатов по документу перед реранком, флаг `RAG_LORE_RERANK_ENABLED` (по умолчанию выключен), бенчмарк `--rerank` и `--retrieval-k`. Сырое ранжирование улучшилось заметно, контекст агента — нет.
- Замер одноразовый на живом провайдере: `Temperature=0`, но ответы модели недетерминированы; при недоступной сети реранкер деградирует к исходному порядку, и метрики совпадают с базовыми.
- Следующий шаг, если возвращаться: cross-encoder на парах «вопрос-пассаж» (без вызова генеративной модели) либо реранк только среди документов, отобранных по title/alias канона.
