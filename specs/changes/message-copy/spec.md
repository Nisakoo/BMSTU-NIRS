# Копирование сообщений в чате

## Цель

Пользователь хочет повторить или поправить свой запрос и сохранить понравившуюся историю. Под каждым сообщением в чате появляется кнопка «Копировать», которая кладёт текст сообщения в буфер обмена. Изменение
затрагивает только frontend.

## Требования

- REQ-001: У каждого сообщения пользователя и у каждого завершённого ответа ассистента (из сохранённой истории или после `message_end`) есть кнопка
  «Копировать» с `aria-label="Скопировать сообщение"`. Пока ответ генерируется и у ответа с `message_error` кнопки нет.
- REQ-002: Нажатие копирует в буфер обмена ровно текст сообщения (без подписей, мордашек и служебных элементов) через `navigator.clipboard.writeText`.
- REQ-003: Если `navigator.clipboard` недоступен (не secure context, например HTTP по IP) или вызов отклонён, используется запасной путь: временный скрытый `textarea` и `document.execCommand("copy")`; после копирования
  `textarea` удаляется.
- REQ-004: При успехе кнопка на 1,5 секунды показывает «Скопировано» и возвращается в исходное состояние. Если оба способа не сработали, строка состояния показывает «Не удалось скопировать».
- REQ-005: Копирование работает независимо от состояния формы: и во время генерации ответа, и при заблокированной форме, и в открытой сохранённой истории. Оно не отправляет сетевых запросов.
- REQ-006: Текст сообщения по-прежнему выводится только через `textContent`.

## Границы

- Всегда: копировать только текст сообщения; не использовать `innerHTML`.
- Сначала спросить: копирование всей истории целиком, редактирование и повторную отправку запроса одной кнопкой.
- Никогда: не менять backend и HTTP-контракт; не сохранять текст в
  `localStorage`.
