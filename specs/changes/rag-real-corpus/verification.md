# Проверка: реальный корпус RAG

Исторический оригинал: `git show 5af56b5:specs/changes/rag-real-corpus/verification.md`.

## Результат

- Структурированный канон расширен до 84 эпизодов. Реальный benchmark собран из 30 настоящих документов и прогнан без БД.
- Реальный набор и 52 новых эпизода лежат только в игнорируемом `data/`; в Git они попадают только через зашифрованный архив, который обновляет владелец данных.
- Персонажи новых эпизодов определены по упоминаниям в тексте; глубокое извлечение interactions, artifacts и locations не выполнялось.
