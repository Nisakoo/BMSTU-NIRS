# План: фраза Смешарика снова в строке с мордашками

Спецификация: [spec.md](./spec.md).

## Задача 1. Вернуть фразу в строку оценки

**Требования:** REQ-001–REQ-004.

**Решение:** в `addFeedback` фраза добавляется в строку оценки после
мордашек, обёртка `sai-report-line` создаётся с одним флажком
(`flex-basis:100%; justify-content:flex-end`). Телефонное правило фразы
(`flex-basis:100%`, постоянная высота) уже действует на дочерний элемент
строки оценки и остаётся.

**Файлы:** `frontend/src/script.js`, `frontend/src/styles.css`,
`frontend/README.md`.

**Проверка:** `make test`; пересборка frontend и CDP на 1280 и 390 px.
