# Verification: кнопка копирования не меняет ширину

Спецификация: [spec.md](./spec.md), план: [plan.md](./plan.md).
Дата проверки: 2026-10-18, ветка `feat/user-dialog-history`.

## Команды

| Команда | Результат |
| --- | --- |
| `make test` | frontend: 183 passed; backend: 397 passed, 36 skipped |
| `docker compose … up -d --build frontend` | контейнер пересобран |

Python-код не менялся. Изменён только CSS, поэтому новых автотестов нет:
fake DOM не считает раскладку. Существующие тесты копирования проходят без
изменений.

## Отклонение от первого варианта

В первой версии спецификации «Скопировано» показывалось всплывающей
подсказкой над кнопкой. По просьбе пользователя подпись убрана совсем:
успех показывает только подсветка квадратика. Спецификация и план обновлены
до реализации.

## Ручная проверка

CDP в headless Chrome на `127.0.0.1:8081`, пользователь `sdd_copy`,
сохранённая история, клик по кнопке копирования ответа.

| Ширина окна | Кнопка до / после / через 1,7 с | Пузырь до / после / через 1,7 с | `scrollWidth` |
| --- | --- | --- | --- |
| 1280 | 32×32 / 32×32 / 32×32 | 640 / 640 / 640 | 1280 |
| 390 | 32×32 / 32×32 / 32×32 | 278 / 278 / 278 | 390 |

После нажатия фон кнопки `rgba(98, 208, 255, 0.16)`, голубые рамка и
галочка; через 1,5 с — исходный вид. Видимого текста нет; текст кнопки в DOM
по-прежнему «Скопировано»/«Копировать».

Скриншоты: `~/Desktop/макеты-смешарики/копирование/63-*.png`.
