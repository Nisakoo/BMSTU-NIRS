# Ещё крупнее карточка входа и регистрации

## Цель

После [login-card-scale](../login-card-scale/spec.md) пользователь просит
сделать окно входа и регистрации на `/login/` «чуть больше и шрифт чуть
больше». Карточка целиком увеличивается ещё в 1,1 раза.

## Требования

- REQ-001: Шрифты карточки умножаются на 1,1 и округляются до 0,5 px.

  | Элемент | Было | Стало |
  | --- | --- | --- |
  | Заголовок | 34 (телефон ≤ 570px — 29) | 37 (32) |
  | Подзаголовок | 16 | 17,5 |
  | Вкладки «Вход/Регистрация» | 16 | 17,5 |
  | Подпись поля | 14,5 | 16 |
  | Текст в поле | 17 | 18,5 |
  | Ошибка под полем | 14 | 15,5 |
  | Сообщение об ошибке | 15 | 16,5 |
  | Кнопка «Войти» / «Зарегистрироваться» | 18 | 20 |

- REQ-002: Размеры карточки умножаются на тот же коэффициент: высоты,
  внутренние отступы, промежутки, скругления.

  | Элемент | Было, px | Стало, px |
  | --- | --- | --- |
  | Поле ввода | 58 | 64 |
  | Вкладка | 47 | 52 |
  | Кнопка | 60 | 66 |
  | Колонка карточки, ≥ 1050px | 400–470 | 440–520 |
  | Колонка карточки, 860–1050px | 360–450 | 400–490 |
  | Карточка, ≤ 860px | до 500 | до 550 |

- REQ-003: Тексты, поведение, цвета, разметка и левая часть страницы не
  меняются.
- REQ-004: Горизонтальной прокрутки нет ни на одной ширине. Если карточка
  регистрации выше экрана, страница прокручивается по вертикали.

## Технологии и структура

- `frontend/src/login/login.css`: размеры карточки, включая медиазапросы.
- Документация не меняется: размеров карточки в ней нет.

## Тестирование

- Существующие Node-тесты страницы входа проходят без изменений.
- Скриншоты headless Chrome: вход и регистрация на 1280×800, узкий экран.

## Критерии приёмки

- [ ] Шрифты и размеры по таблицам REQ-001 и REQ-002.
- [ ] Нет горизонтальной прокрутки; `npm --prefix frontend test` проходит.
