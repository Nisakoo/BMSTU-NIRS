# Проверка: активное состояние навигации панели администратора

Исторический оригинал: `git show 5af56b5:specs/changes/admin-active-navigation/verification.md`.

## Результат

- Изменение соответствует спецификации. Активное состояние навигации панели администратора синхронизируется с выбранной ссылкой и поддерживаемым URL hash; одновременно `aria-current="location"` имеет ровно одна ссылка.
- Автоматический scrollspy при ручной прокрутке без изменения URL hash не входит в согласованный scope. Активный раздел определяется кликом по навигационной ссылке или текущим hash.
