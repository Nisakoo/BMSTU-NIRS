# Проверка: активное состояние навигации панели администратора

## Результат

Изменение соответствует спецификации. Активное состояние навигации панели
администратора синхронизируется с выбранной ссылкой и поддерживаемым URL hash;
одновременно `aria-current="location"` имеет ровно одна ссылка.

## Проверка требований

| Требование | Подтверждение | Результат |
| --- | --- | --- |
| REQ-001 | DOM-тест `navigation activates overview by default...` проверяет пустой hash и активный «Обзор» | Пройдено |
| REQ-002 | Тот же DOM-тест нажимает «Активность» и проверяет снятие состояния с «Обзор» | Пройдено |
| REQ-003 | DOM-тест ищет единственный `aria-current="location"`; CSS использует тот же доступный атрибут | Пройдено |
| REQ-004 | DOM-тест начинает с `#users`, затем имитирует `hashchange` на `#activity` | Пройдено |
| REQ-005 | DOM-тест меняет hash на `#missing` и подтверждает безопасный fallback на «Обзор»; существующие тесты dashboard проходят | Пройдено |

## Критерии приёмки

- После выбора «Активность» ссылка «Обзор» теряет `aria-current` и активную
  подсветку.
- Единственное активное состояние соответствует выбранной ссылке или
  поддерживаемому hash.
- Программное состояние и CSS согласованы на `aria-current="location"`.
- Инициализация по прямому hash и обработка `hashchange` покрыты тестом.
- Отрисовка демонстрационных данных и переключение периода проходят прежние
  тесты без регрессий.

## Scope и документация

Изменены только локальное состояние существующей admin-навигации, её доступный
HTML-атрибут, соответствующий CSS-селектор и тесты поведения. Backend,
пользовательский чат, маршруты и архитектурные контракты не изменены;
обновление архитектурной документации не требуется.

## Известные ограничения

Автоматический scrollspy при ручной прокрутке без изменения URL hash не входит
в согласованный scope. Активный раздел определяется кликом по навигационной
ссылке или текущим hash.
