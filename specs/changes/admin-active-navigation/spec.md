# Активное состояние навигации панели администратора

## Цель

Исправить навигацию панели администратора так, чтобы визуально и программно активным был выбранный пользователем раздел, а ссылка «Обзор» не оставалась подсвеченной после перехода к другим разделам страницы.

## Требования

- REQ-001: При открытии `/admin/` без поддерживаемого hash активной является ссылка «Обзор».
- REQ-002: При выборе ссылки «Обзор», «Активность» или «Пользователи» активное состояние переносится только на выбранную ссылку; ранее выбранная ссылка перестаёт быть активной.
- REQ-003: Активная ссылка программно обозначается атрибутом
  `aria-current="location"`, чтобы состояние было доступно не только визуально.
- REQ-004: При открытии страницы с hash `#overview`, `#activity` или `#users`, а также при изменении hash средствами браузера, активная ссылка соответствует указанному разделу.
- REQ-005: Неизвестный или пустой hash безопасно выбирает «Обзор» и не нарушает существующую отрисовку демонстрационных данных и переключение периода.

## Границы

- Всегда: сохранять существующие ссылки-якоря, стили активного состояния, клавиатурную доступность и работу остальных элементов панели.
- Сначала спросить: добавлять новые разделы, автоматическое переключение подсветки при ручной прокрутке без изменения hash или менять внешний вид навигации.
- Никогда: добавлять backend-запросы, новые runtime-зависимости или изменять пользовательский чат в рамках этого исправления.
