# План: активное состояние навигации панели администратора

## Задача 1. Зафиксировать контракт навигации тестами

- Требования: REQ-001–REQ-005.
- Критерии приёмки: после выбора активна ровно одна соответствующая ссылка;
  прямой, изменённый, пустой и неизвестный hash дают ожидаемое состояние;
  существующая отрисовка панели не регрессирует.
- Зависимости: существующая DOM-обвязка тестов административной панели.
- Файлы: `frontend/tests/admin-ui.test.js`.
- Реализация: расширить тестовый DOM ссылками навигации и имитацией
  `location.hash`/`hashchange`; сначала добавить падающие проверки начального
  состояния, клика и изменения hash.
- Проверка: `npm --prefix frontend test -- --test-name-pattern="navigation"`.

## Задача 2. Синхронизировать активную ссылку с hash

- Требования: REQ-001–REQ-005.
- Критерии приёмки: «Обзор» не остаётся активным после выбора другого раздела;
  `aria-current="location"` присутствует только у актуальной ссылки; fallback
  для неизвестного hash работает безопасно.
- Зависимости: проверки задачи 1.
- Файлы: `frontend/src/admin/admin.js`, `frontend/src/admin/index.html`,
  `frontend/src/admin/admin.css`.
- Реализация: убрать жёстко заданное состояние `page`, добавить отдельную
  инициализацию навигации, которая нормализует поддерживаемый hash, обновляет
  `aria-current` при клике и `hashchange` и не зависит от данных dashboard;
  существующий CSS-селектор активной ссылки перевести на значение `location`.
- Проверка: целевые тесты навигации, затем `npm --prefix frontend test`.

## Задача 3. Проверить сборку и отсутствие регрессий

- Требования: все требования спецификации и критерии отсутствия регрессий.
- Критерии приёмки: frontend собирается; существующие тесты панели,
  пользовательского чата и полный набор тестов продукта проходят.
- Зависимости: задачи 1–2.
- Файлы: изменения не предполагаются; при выявленной регрессии исправляется
  минимальный относящийся к ней файл.
- Проверка: `npm --prefix frontend run build`, `make test`, визуальная проверка
  семантики навигации в собранном HTML.

## Документация

Изменение исправляет локальное интерактивное состояние существующей навигации
и не меняет архитектуру, публичные маршруты, API или контракт сборки. Поэтому
`docs/README.md` и тематические архитектурные страницы обновлять не требуется.
