## Найденный дефект

Первая проверка настоящими событиями мыши показала:

- панель открыта, курсор на кнопке — кнопка выглядит как при наведении
  (`rgba(98,208,255,.13)`, белого текста нет);
- открытое состояние видно, только когда курсор уводят с кнопки.

**Причина** — специфичность CSS. Правило
`.sai-length-button:hover:not(:disabled)` весит больше, чем
`.sai-length-button[aria-expanded="true"]`, и перебивает его. Из-за этого
сразу после нажатия кнопка не выделялась: это и было в жалобе пользователя.

**Исправление.** Добавлен селектор
`.sai-length-button[aria-expanded="true"]:hover:not(:disabled)`.

**Тесты.** Автотест на каскад CSS в fake DOM невозможен. Исправление
подтверждено повторной проверкой по шагам (ниже).
