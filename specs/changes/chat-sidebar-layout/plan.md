# План: чат с боковой панелью «Мои истории»

Спецификация: [spec.md](./spec.md). Зависит от
[user-dialog-history](../user-dialog-history/spec.md): реализуется после него.

## Порядок

Сначала клиент API с тестами — это фиксирует контракт с backend. Затем новая
разметка и стили. Затем логика панели в `script.js` с UI-тестами на fake DOM.
Документация, скриншоты и ручная проверка с реальным backend — последними.

## Задача 1. Клиент API списка и истории

**Требования:** REQ-015.

**Критерии приёмки:** `listDialogs()` и `getMessages(id)` выполняют запросы с
закодированным `dialog_id`, разбирают ответы в описанные структуры и
выбрасывают `unauthorized`, `not_found`, `load_failed`, `invalid_response`.

**Файлы:** `frontend/src/agent-api.js`, `frontend/tests/agent-api.test.js`.

**Проверка:** `npm --prefix frontend test`.

## Задача 2. Разметка и стили

**Требования:** REQ-001…REQ-004.

**Критерии приёмки:** боковая панель, шапка с названием и состоянием, лента,
композер и чипы; удалены заголовок, сцена-рамка, персонажи, луна и подсказка;
приглушённые холмы фоном; на `≤820px` кнопка «Истории» и выезжающая панель с
затемнением.

**Файлы:** `frontend/src/index.html`, `frontend/src/styles.css`.

**Проверка:** скриншоты headless Chrome на контрольных viewport.

## Задача 3. Логика панели

**Требования:** REQ-005…REQ-014.

**Критерии приёмки:** список загружается после проверки сессии; выбор истории
закрывает прежний `EventSource`, загружает сообщения и открывает новый;
«Новая история» создаёт диалог; переключение недоступно во время ответа;
список перезагружается после `message_end`; ошибки списка и истории
обрабатываются по REQ-011; динамический текст — только `textContent`;
мобильная панель открывается и закрывается; прежние сценарии сессии и потока
работают. Тесты подсказки Кроша удаляются.

**Файлы:** `frontend/src/script.js`, `frontend/tests/ui.test.js`.

**Проверка:** `npm --prefix frontend test`.

## Задача 4. Документация

**Файлы:** `frontend/README.md`, `docs/README.md`, `docs/dialogs.md` (раздел
frontend при наличии), `AGENTS.md` (раздел «Реализованный frontend»: чат с
боковой панелью вместо подсказки Кроша и нового диалога без списка).

**Проверка:** ревью.

## Задача 5. Визуальная и ручная проверка

**Проверка:** `make run`; скриншоты `1440x900`, `1280x720`, `768x1024`,
`375x800`, `320x640`; ручной сценарий: две истории, переключение,
продолжение, перезагрузка страницы, выход; `make test`.
