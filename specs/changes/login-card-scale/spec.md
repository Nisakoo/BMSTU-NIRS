# Крупнее карточка входа и регистрации

## Цель

Карточку входа и регистрации на `/login/` трудно читать. Самый мелкий
текст — ошибка под полем — набран 12,5 px. Карточка целиком увеличивается
в 1,12 раза (14 ÷ 12,5), чтобы самый мелкий шрифт стал 14 px, а остальные
размеры выросли пропорционально. Превью согласовано:
`макеты-смешарики/вход-карточка/`.

## Требования

- REQ-001: Шрифты карточки умножаются на 1,12 и округляются до 0,5 px.
  Ни один шрифт карточки не меньше 14 px.

  | Элемент | Было | Стало |
  | --- | --- | --- |
  | Заголовок | 30 (телефон ≤ 570px — 26) | 34 (29) |
  | Подзаголовок | 14 | 16 |
  | Вкладки «Вход/Регистрация» | 14,5 | 16 |
  | Подпись поля | 13 | 14,5 |
  | Текст в поле | 15 | 17 |
  | Ошибка под полем | 12,5 | 14 |
  | Сообщение об ошибке | 13,5 | 15 |
  | Кнопка «Войти» / «Зарегистрироваться» | 16 | 18 |

- REQ-002: Размеры элементов карточки умножаются на тот же коэффициент 1,12:
  высоты, внутренние отступы, промежутки, скругления.

  | Элемент | Было, px | Стало, px |
  | --- | --- | --- |
  | Поле ввода | 52 | 58 |
  | Вкладка | 42 | 47 |
  | Кнопка | 54 | 60 |
  | Колонка карточки, ≥ 1050px | 360–420 | 400–470 |
  | Колонка карточки, 860–1050px | 330–400 | 360–450 |
  | Карточка, ≤ 860px | до 460 | до 500 |

- REQ-003: Тексты, поведение, цвета, разметка и левая часть страницы
  (заголовок, Смешарики) не меняются.
- REQ-004: Горизонтальной прокрутки нет ни на одной ширине. Если карточка
  с ошибками регистрации выше экрана, страница прокручивается по вертикали.
  По превью: на 1280×800 разница 6 px. Это допустимо.

## Сценарии

### Регистрация с ошибками

- Given открыта вкладка «Регистрация»
- When пользователь отправляет пустую форму
- Then ошибки под полями набраны 14 px, остальной текст карточки
  пропорционально крупнее

## Технологии и структура

- `frontend/src/login/login.css`: размеры карточки, включая медиазапросы.
- Документация не меняется: в ней нет размеров карточки.

## Команды

- Тесты: `make test`
- Сборка: `npm --prefix frontend run build`

## Тестирование

- Существующие Node-тесты страницы входа проходят без изменений.
- Ручная проверка через `cdp.mjs` на 1440×900, 1280×800, 1366×768,
  900×1000 и 390×844:
  - минимальный `font-size` среди всех элементов карточки (вход и
    регистрация с ошибками) равен 14 px;
  - замер высот;
  - нет горизонтальной прокрутки;
  - скриншоты.

## Границы

- Всегда: менять только размеры карточки.
- Сначала спросить: изменение текстов, цветов, левой части страницы.
- Никогда: менять разметку и поведение формы.

## Критерии приёмки

- [ ] Минимальный шрифт карточки — 14 px, остальные крупнее
  пропорционально.
- [ ] Поля, вкладки и кнопка пропорционально выше, карточка шире.
- [ ] `make test` проходит; горизонтальной прокрутки нет.
