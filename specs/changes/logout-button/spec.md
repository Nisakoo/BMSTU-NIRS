# Кнопка выхода в чате и панели администратора

## Цель

Пользователь чата `/` и администратор на `/admin/` могут завершить сессию кнопкой «Выйти» и попасть на страницу входа и регистрации `/login/`. Backend
уже реализует `POST /api/v1/auth/logout` (см. [`docs/auth.md`](../../../docs/auth.md)); изменение затрагивает только frontend и документацию.

## Требования

- REQ-001: На странице чата `/` есть кнопка «Выйти» (`<button type="button">`) в нижней части боковой панели, доступная с клавиатуры и видимая на desktop и mobile без перекрытия формы ввода.
- REQ-002: На странице `/admin/` есть кнопка «Выйти» в нижней части боковой панели под ссылкой на пользовательский чат; на узких экранах она остаётся доступной.
- REQ-003: Нажатие отправляет `AuthApi.logout()` (`POST /api/v1/auth/logout` без тела, `credentials: "same-origin"`). На время запроса кнопка заблокирована, повторные нажатия не отправляют новых запросов.
- REQ-004: После `204` страница выполняет `location.replace("/login/")`. В чате перед переходом закрывается `EventSource` и отменяется отложенный повтор создания диалога; незавершённый ответ агента не ожидается.
- REQ-005: Если запрос выхода не удался (сеть, `503`, другой статус), страница остаётся на месте, кнопка снова доступна, показывается сообщение «Не удалось
  выйти. Попробуйте ещё раз»: в чате — в уведомлении над полем ввода, в админке — в существующем блоке ошибки или рядом с кнопкой. Переход на `/login/` не
  выполняется, потому что при ошибке backend cookie сессии не сбрасываются.
- REQ-006: Кнопка не читает и не удаляет cookie из JavaScript и не использует
  `localStorage`/`sessionStorage`: сессию завершает backend.
- REQ-007: Документация (`docs/auth.md`, `frontend/README.md`, `AGENTS.md`) описывает кнопки выхода; пункт «кнопка выхода» удаляется из «Что пока не реализовано».

## Границы

- Всегда: только `textContent` для сообщений; переход через
  `location.replace`.
- Сначала спросить: подтверждение перед выходом, выход со страницы `/login/`, показ логина пользователя рядом с кнопкой.
- Никогда: удаление cookie или хранение токенов в JavaScript.
