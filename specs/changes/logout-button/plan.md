# План: кнопка выхода в чате и панели администратора

Спецификация: [spec.md](./spec.md). Backend не меняется: используется
существующий `AuthApi.logout()`.

## Задача 1. Выход из чата

**Требования:** REQ-001, REQ-003…REQ-006.

**Критерии приёмки:** в шапке чата есть `#saiLogout`; нажатие блокирует
кнопку и отправляет один `POST /api/v1/auth/logout`; после `204` закрывается
`EventSource`, отменяется таймер повтора и выполняется
`location.replace("/login/")`; при ошибке статус «Не удалось выйти.
Попробуйте ещё раз», кнопка разблокирована, перехода нет. На ширине ≤570px
строка статуса видна в состоянии `error`.

**Зависимости:** нет.

**Файлы:** `frontend/src/index.html`, `frontend/src/styles.css`,
`frontend/src/script.js`, `frontend/tests/ui.test.js`.

**Проверка:** `npm --prefix frontend test`.

## Задача 2. Выход из панели администратора

**Требования:** REQ-002…REQ-006.

**Критерии приёмки:** в нижней части боковой панели есть `#adminLogout`,
видимая и на узких экранах; поведение запроса и ошибки такое же, как в чате;
сообщение об ошибке выводится в `#adminLogoutError` рядом с кнопкой, не скрывая
панель. Обработчик подключается в `mountAdminPage` только после успешной
проверки роли `admin`.

**Зависимости:** нет.

**Файлы:** `frontend/src/admin/index.html`, `frontend/src/admin/admin.css`,
`frontend/src/admin/admin.js`, `frontend/tests/admin-ui.test.js`.

**Проверка:** `npm --prefix frontend test`.

## Задача 3. Документация и итоговая проверка

**Требования:** REQ-007.

**Критерии приёмки:** `docs/auth.md`, `frontend/README.md`, `AGENTS.md`
описывают кнопки выхода; пункт удалён из «Что пока не реализовано».

**Зависимости:** задачи 1–2.

**Проверка:** ревью документации; `make test`, `make lint`,
`npm --prefix frontend run build`; ручная проверка в `make run`.
