## Ручная проверка

Compose-стек на `127.0.0.1:8081`, пользователь `sdd_krosh`, администратор
`sdd_admin`.

- **Миграция.** До неё в `message_feedback` лежали `like`, `dislike`, `like`,
  `like`. После `make migrate` значения стали 5, 1, 5, 5.
- **Откат миграции** проверен скриптом на временной базе:
  - баллы 1–5 после downgrade до `0003` стали `dislike`, `dislike`, `like`,
    `like`, `like`;
  - повторный upgrade дал 1, 1, 5, 5, 5.
- **Чат, компьютер 1280px.**
  - В сохранённой истории со старым 👍 выбран Крош с фразой «Крош в
    восторге!».
  - Клик по Копатычу у ответа со старым 👎 сохранил балл 4: это подтвердил
    `GET .../messages`.
  - При наведении на Нюшу появляется подпись «Скорее не понравилось», а
    невыбранные мордашки приглушены.
- **Чат, телефон 390px.** Подпись «Как тебе история?» стоит над рядом
  мордашек. `scrollWidth` равен ширине экрана. В отчёте за краем экрана
  только скрытая off-canvas панель историй.
- **Админка, 30 дней.** API вернул
  `{"answers_total": 8, "rated_answers": 4, "counts": [0, 0, 0, 1, 3]}`.
  - Панель показывает «4,8 из 5», мордашку Кроша и «оценено 4 из 8 ответов».
  - Полосы: 3 / 1 / 0 / 0 / 0 для баллов 5 / 4 / 3 / 2 / 1.
  - Горизонтальной прокрутки нет ни на 1280px, ни на 390px.
- **Сборка.** Vite встроил пять SVG в страницы как `data:` URI, потому что
  каждый файл меньше лимита встраивания 4 КБ. Отдельные файлы с хешем, как
  предполагал план, не появились. Мордашки отображаются корректно.

Скриншоты лежат в `~/Desktop/макеты-смешарики/14–18`.

## Замена картинок (после verify)

По просьбе пользователя SVG заменены на присланные PNG в 3D-стиле. Персонажи,
эмоции и порядок шкалы остались прежними.

- **Подготовка.** У Нюши, Лосяша, Копатыча и Кроша не было прозрачности:
  белый фон, у Кроша нарисованная «шахматка». Фон и тени на полу удалены
  скриптом. Белые детали внутри персонажа сохранены, цветок Нюши проверен
  крупно. Все пять картинок обрезаны и уменьшены до 256×256 PNG, по
  70–100 КБ каждая. Оригиналы (1,5–2 МБ) в репозиторий не добавлялись.
- **Проверка.** Frontend-тесты: 129 passed. Сборка проходит. Скриншоты чата
  (1280 и 390 px) и админки — в `~/Desktop/макеты-смешарики/21–24`.
- **Источник картинок.** Пользователь не указал, откуда они взяты. Перед
  публикацией нужно записать источник.

### Крупные лица

По просьбе пользователя эмоцию сделали различимой без подписи.

- **Кадр.** Каждая картинка — лицо крупным планом с мягким круглым краем.
  Рога, шляпа, очки и уши частично входят в кадр, чтобы персонажа можно было
  узнать.
- **Размер.** Кнопка в чате увеличена с 40 до 52 px, на телефоне до 48 px.
  В админке мордашка средней оценки 68 px, в строках распределения 38 px.
- **Исходники.**
  - Нюша — новый крупный план от пользователя. У файла не было
    прозрачности: был белый фон с «шахматкой», его удалили скриптом.
  - Ёжик — по выбору пользователя возвращён прежний грустный. Присланный
    улыбающийся не подходит для оценки 1.
  - Остальные три — прозрачные версии от пользователя.
- **Проверка.** Frontend-тесты: 129 passed. Сборка проходит. Скриншоты
  1280 и 390 px и админки — в `~/Desktop/макеты-смешарики/27–30`.
