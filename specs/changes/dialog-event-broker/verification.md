## Результат

- Изменение соответствует спецификации. Управление подписками вынесено из `AgentService` в абстракцию `DialogEventBroker`; production composition root использует `InMemoryDialogEventBroker`. Публичные HTTP- и SSE-контракты не изменились.

- Реализация хранит подписки только в одном процессе и теряет их при рестарте.
- Replay и `Last-Event-ID` не поддерживаются.
- Переполненная очередь закрывает только медленного подписчика; события для него не восстанавливаются.
- Размер очереди по умолчанию равен 64 и не настраивается через environment.
- Постоянный или межпроцессный брокер в изменение не входит.
