# smeshariki-ai

НИРС-проект «Смешарики AI».

## Структура

- `frontend/` — пользовательский интерфейс;
- `backend/` — API, runtime агента, серверная бизнес-логика и RAG;
- `docker/` — контейнерный запуск backend и его инфраструктуры;
- `specs/` — спецификации, планы и результаты проверки SDD-изменений.

Frontend запускается отдельно от Docker-окружения backend. Агент и RAG входят
в состав единого backend-приложения.

## Команды

- `make run` — запуск backend и его инфраструктуры после добавления необходимой
  конфигурации;
- `make test` — запуск автоматических тестов Python-кода продукта после их
  добавления.

Сейчас репозиторий содержит только базовый каркас. Запускаемое приложение и
продуктовые тесты будут добавляться отдельными SDD-изменениями.
