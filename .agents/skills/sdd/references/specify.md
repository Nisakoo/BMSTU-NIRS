# Specify

1. Изучи запрос, `AGENTS.md` и относящийся к задаче код.
2. Явно перечисли важные допущения и уточни неоднозначности.
3. Создай `specs/changes/<change-id>/spec.md` по [шаблону](spec-template.md).
4. Требования и критерии приёмки формулируй наблюдаемым и проверяемым образом.
5. Не создавай код и будущую структуру проекта на этом этапе.
6. Покажи спецификацию пользователю и дождись явного одобрения.

Если запрос содержит несколько независимо проверяемых возможностей, сначала предложи их разбиение и порядок реализации.
